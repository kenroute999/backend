# Task 2 — Multi-Tenant Prisma Schema Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Translate the approved schema design (`docs/superpowers/specs/2026-07-22-multi-tenant-schema-design.md`) into a working `schema.prisma`, apply it as a migration to `kenroute_dev` and `kenroute_test`, and produce a reusable Prisma client, seed script, and test database helpers for later tasks to build on.

**Architecture:** One `schema.prisma` file defines 10 models covering the core booking flow, every one scoped by `operatorId`. A singleton `PrismaClient` (`src/db/prisma.ts`) is the only way application code touches the database. `prisma/seed.ts` populates one demo operator for manual testing. `tests/helpers/db.ts` and `tests/helpers/factories.ts` give every later task a consistent way to reset and populate the test database.

**Tech Stack:** Prisma 7.9.0 (`prisma-client` generator, CommonJS output), PostgreSQL 18 (databases `kenroute_dev` / `kenroute_test` already provisioned), TypeScript 7 (`module: nodenext`), ts-node 10.9.2, bcrypt 6.

## Global Constraints

- Every table has an `operatorId` column — no exceptions among the 10 in-scope models (spec §5).
- `Booking.seatId` stays `@unique` — a seat can only ever be booked once (spec §3.2).
- `Booking.pnr` is indexed, not unique — grouped seats share a PNR (spec §3.2).
- Root `package.json` `"type"` stays `"commonjs"` — do not migrate the project to ESM. The Prisma client generator must be configured with `moduleFormat = "cjs"` to match (discovered during planning: the default generator output uses `import.meta.url`, which is invalid under CommonJS).
- `.env` is git-ignored; edit it directly, never commit secrets.
- No new dependencies beyond what's already installed (`bcrypt`, `ts-node`) — no `tsx`, no ORM abstraction layers.

- [ ] **Step 2: Write `prisma/schema.prisma`**

```prisma
generator client {
  provider     = "prisma-client"
  output       = "../generated/prisma"
  moduleFormat = "cjs"
}

datasource db {
  provider = "postgresql"
}

enum UserRole {
  OWNER
  AGENT
  CONDUCTOR
}

enum ChannelType {
  OWN_AGENT
  REDBUS
  ABHIBUS
}

enum ChannelStatus {
  ACTIVE
  NOT_CONFIGURED
}

enum SeatStatus {
  AVAILABLE
  HELD
  BOOKED
}

enum BookingStatus {
  CREATED
  CONFIRMED
  BOARDED
  COMPLETED
  CANCELLED
  REFUNDED
}

enum CommissionStatus {
  PENDING
  PAID
}

model Operator {
  id        String   @id @default(uuid())
  name      String
  plan      String   @default("standard")
  createdAt DateTime @default(now())

  users       User[]
  buses       Bus[]
  busRoutes   BusRoute[]
  channels    Channel[]
  trips       Trip[]
  seats       Seat[]
  bookings    Booking[]
  passengers  Passenger[]
  commissions CommissionLedger[]
}

model User {
  id           String   @id @default(uuid())
  operatorId   String
  operator     Operator @relation(fields: [operatorId], references: [id])
  role         UserRole
  name         String
  email        String
  passwordHash String
  createdAt    DateTime @default(now())

  agentBookings    Booking[]          @relation("AgentBookings")
  agentCommissions CommissionLedger[] @relation("AgentCommissions")
  conductedTrips   Trip[]             @relation("ConductorTrips")

  @@unique([operatorId, email])
  @@index([operatorId])
}

model Bus {
  id             String   @id @default(uuid())
  operatorId     String
  operator       Operator @relation(fields: [operatorId], references: [id])
  registrationNo String
  type           String
  totalSeats     Int
  createdAt      DateTime @default(now())

  trips Trip[]

  @@unique([operatorId, registrationNo])
  @@index([operatorId])
}

model BusRoute {
  id          String   @id @default(uuid())
  operatorId  String
  operator    Operator @relation(fields: [operatorId], references: [id])
  origin      String
  destination String
  distanceKm  Int?
  createdAt   DateTime @default(now())

  trips Trip[]

  @@index([operatorId])
}

model Channel {
  id         String        @id @default(uuid())
  operatorId String
  operator   Operator      @relation(fields: [operatorId], references: [id])
  type       ChannelType
  status     ChannelStatus @default(NOT_CONFIGURED)
  apiCreds   Json?
  createdAt  DateTime      @default(now())

  bookings Booking[]

  @@unique([operatorId, type])
  @@index([operatorId])
}

model Trip {
  id          String   @id @default(uuid())
  operatorId  String
  operator    Operator @relation(fields: [operatorId], references: [id])
  busId       String
  bus         Bus      @relation(fields: [busId], references: [id])
  busRouteId  String
  busRoute    BusRoute @relation(fields: [busRouteId], references: [id])
  conductorId String?
  conductor   User?    @relation("ConductorTrips", fields: [conductorId], references: [id])
  departureAt DateTime
  status      String   @default("scheduled")
  createdAt   DateTime @default(now())

  seats    Seat[]
  bookings Booking[]

  @@index([operatorId])
  @@index([operatorId, departureAt])
  @@index([operatorId, conductorId])
}

model Seat {
  id         String     @id @default(uuid())
  operatorId String
  operator   Operator   @relation(fields: [operatorId], references: [id])
  tripId     String
  trip       Trip       @relation(fields: [tripId], references: [id])
  seatNumber String
  deck       String     @default("lower")
  status     SeatStatus @default(AVAILABLE)

  booking Booking?

  @@unique([tripId, seatNumber])
  @@index([operatorId])
}

model Booking {
  id           String        @id @default(uuid())
  operatorId   String
  operator     Operator      @relation(fields: [operatorId], references: [id])
  tripId       String
  trip         Trip          @relation(fields: [tripId], references: [id])
  seatId       String        @unique
  seat         Seat          @relation(fields: [seatId], references: [id])
  channelId    String
  channel      Channel       @relation(fields: [channelId], references: [id])
  agentId      String?
  agent        User?         @relation("AgentBookings", fields: [agentId], references: [id])
  fare         Decimal       @db.Decimal(10, 2)
  pnr          String
  status       BookingStatus @default(CREATED)
  refundAmount Decimal?      @db.Decimal(10, 2)
  createdAt    DateTime      @default(now())

  passenger  Passenger?
  commission CommissionLedger?

  @@index([operatorId])
  @@index([operatorId, pnr])
}

model Passenger {
  id         String    @id @default(uuid())
  operatorId String
  operator   Operator  @relation(fields: [operatorId], references: [id])
  bookingId  String    @unique
  booking    Booking   @relation(fields: [bookingId], references: [id])
  name       String
  phone      String
  idProof    String?
  boarded    Boolean   @default(false)
  boardedAt  DateTime?

  @@index([operatorId])
}

model CommissionLedger {
  id         String           @id @default(uuid())
  operatorId String
  operator   Operator         @relation(fields: [operatorId], references: [id])
  agentId    String
  agent      User             @relation("AgentCommissions", fields: [agentId], references: [id])
  bookingId  String           @unique
  booking    Booking          @relation(fields: [bookingId], references: [id])
  amount     Decimal          @db.Decimal(10, 2)
  status     CommissionStatus @default(PENDING)
  paidAt     DateTime?
  createdAt  DateTime         @default(now())

  @@index([operatorId])
  @@index([operatorId, agentId])
}
```

```typescript
import { PrismaClient, ChannelType, ChannelStatus, UserRole } from "../generated/prisma/client";
import bcrypt from "bcrypt";

const prisma = new PrismaClient();

async function main() {
  const operator = await prisma.operator.create({
    data: { name: "Sri Krishna Travels" },
  });

  await prisma.channel.createMany({
    data: [
      { operatorId: operator.id, type: ChannelType.OWN_AGENT, status: ChannelStatus.ACTIVE },
      { operatorId: operator.id, type: ChannelType.REDBUS, status: ChannelStatus.NOT_CONFIGURED },
      { operatorId: operator.id, type: ChannelType.ABHIBUS, status: ChannelStatus.NOT_CONFIGURED },
    ],
  });

  const passwordHash = await bcrypt.hash("Password123!", 10);
  await prisma.user.create({
    data: {
      operatorId: operator.id,
      role: UserRole.OWNER,
      name: "Owner Demo",
      email: "owner@srikrishna.test",
      passwordHash,
    },
  });

  console.log(`Seeded operator ${operator.id} with an OWNER login: owner@srikrishna.test / Password123!`);
}

main()
  .catch((error) => {
    console.error(error);
    process.exitCode = 1;
  })
  .finally(() => prisma.$disconnect());
```

```typescript
import { PrismaClient } from "../../generated/prisma/client";

export const testPrisma = new PrismaClient({
  datasources: { db: { url: process.env["DATABASE_URL_TEST"] } },
});

export async function resetDb(): Promise<void> {
  const tables = [
    "CommissionLedger",
    "Passenger",
    "Booking",
    "Seat",
    "Trip",
    "Channel",
    "BusRoute",
    "Bus",
    "User",
    "Operator",
  ];
  for (const table of tables) {
    await testPrisma.$executeRawUnsafe(`TRUNCATE TABLE "${table}" CASCADE`);
  }
}

export async function disconnectDb(): Promise<void> {
  await testPrisma.$disconnect();
}
```

```typescript
      email: overrides.email ?? `${role.toLowerCase()}-${Date.now()}@test.com`,
      passwordHash,
    },
  });
  return { user, plainPassword };
}
```

- **Spec coverage:** §1 (scope) → both tasks only touch the 10 in-scope entities. §2 (definitions) → Task 1 Step 2. §3.1 (Trip.conductorId) → `Trip` model + `User.conductedTrips`. §3.2 (Booking pnr/refund) → `Booking` model. §4 (relationships) → matches the schema's foreign keys. §5 (tenant isolation) → every model has `operatorId` + index. §6 (RBAC matrix) → not schema work; belongs to Task 4 (middleware) in the original 13-task plan, correctly out of scope here. §7 (constraints) → unique/index annotations throughout. §8 (migration plan) → Task 1 Steps 4–8.
- **Forward-reference check:** the original draft schema referenced `hashPassword` from `src/utils/password.ts`, a file that doesn't exist until Task 3. Replaced with direct `bcrypt.hash(...)` calls in both `seed.ts` and `factories.ts` (matching each other) to keep this plan fully self-contained.
- **Toolchain check:** confirmed empirically during planning — `moduleFormat = "cjs"` removes the `import.meta.url` shim from the generated client (verified by regenerating and inspecting output), and `tsconfig.json`'s `"types": []` would otherwise block `process.env` access in every new file.
